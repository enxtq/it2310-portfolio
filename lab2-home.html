Welcome to Lab 2

In this lab, I'm learning how to create a multi-page website with navigation links and tables. I'll be using relative and absolute paths to link pages within my site and to external websites. Additionally, I'll be building HTML tables with accessibility features and practicing good Git habits by committing changes with clear, descriptive messages. By the end, I'll have gained practical skills in creating and organizing web pages, as well as ensuring they are accessible and well-documented.
